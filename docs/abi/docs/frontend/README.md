## Architecture Summary (V3)

Primary production lane (see [CurrentSmartContract.md](../CurrentSmartContract.md)):

1. **Curated draft** → `MarketDraftBoard.proposeDraft` (settlement asset, min seed)
2. **Claim & seed** → `DraftClaimManager.claimAndSeed` → per-draft `LiquidityVault4626`
3. **Publish** → `CREPublishReceiver` → `MarketFactory.createFromDraft` → `MarketRegistry` + risk cap
4. **Trade** → Offchain; settle via `ChannelSettlement` (mint/burn `OutcomeToken1155`, reserve LP payout)
5. **Resolve** → Oracle → `SettlementRouter` → `MarketRegistry`
6. **Redeem** → `MarketRegistry.redeem` (burn winning 1155, payout from vault)

## V3 Notes

Aligned with [CurrentSmartContract.md](../CurrentSmartContract.md):

- **OutcomeToken1155** — Canonical ERC-1155 outcome positions; transfer-locked until market resolved; redeem uses `burnForRedeem`
- **3-bucket vaults (V3-Escrow):** `freeBalance`, `reservedBalance` (storage); `availableBalance = max(0, freeBalance - reservedBalance)` (withdrawable); `lockedBalance` (per-session, challenge window). Reserve on checkpoint submit; release on finalize or `cancelPendingCheckpoint` (6h delay)
- **MarketRiskManager:** LP payout cap per market; `reserveLpPayout` enforces cap; `setMaxLpPayout` via `createFromDraft` (minSeed × lpExposureMultiplier)
- **createFromDraft:** When `DraftClaimManager` is configured, publish requires SEEDED claim and liquidity vault
- **ExecutionLedger:** Deprecated; kept for legacy backward compat when `outcomeToken == 0`
- **Faucet:** Testnet token claims (DeployBetaTestnet)
