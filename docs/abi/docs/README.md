# Smart Contract Integration Documentation

**Last updated:** 2026-03-01  
**Purpose:** ABI artifacts and integration documentation for RetroPick smart contracts.

---

## 1. Overview

The `docs/abi/` directory contains:

- **JSON ABIs** — Per-contract ABI files in `docs/abi/*.json` (e.g. `ChannelSettlement.json`, `CREReceiver.json`) for frontend and tooling. Generated by `scripts/export_abis_to_docs.sh` or `scripts/verify_and_export_abis_fuji.sh`
- **docs/** — Integration guides, architecture, and development context

## 4. ABI Generation

| Script | Purpose |
|--------|---------|
| `scripts/verify_and_export_abis_fuji.sh` | Verify all DeployBetaTestnet contracts on Snowtrace (Fuji) and export ABIs to `docs/abi/` |
| `scripts/export_abis_to_docs.sh` | Export ABIs only (no verification); use `SKIP_VERIFY=1` for the former to achieve the same |
